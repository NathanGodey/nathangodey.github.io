Copy-attention visualization

Each box is a token. Box redness ∝ α = P(<copy>) at that position. Curved arrow goes from query token t back to the source position j* = where the copy distribution argmax was pulled from. Arrow width and opacity scale with α; arrows within the same row are red, arrows spanning rows are blue. Only arrows with α > 0.15 are drawn. Hover any box for exact α and full token text.
