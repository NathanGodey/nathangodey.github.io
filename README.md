# nathangodey.github.io

Source of [nathangodey.github.io](https://nathangodey.github.io). Plain Jekyll, no theme.

- Publications, news and co-author links are data: `_data/*.yml`.
- `python3 tools/add_paper.py <arxiv-id>` drafts a new publication entry.
- `bundle install && bundle exec jekyll serve` to preview locally.

See [CLAUDE.md](CLAUDE.md) for the full guide (written for both humans and coding agents).
